# sql-data-warehouse-and-analytics-project
This project demonstrate a comprehensive datawarehouse from building datawarehouse to generating analytical insights and data models 
🚀 Project Overview

This project is part of my learning journey in data engineering and analytics. The goal is to design and build a modern data warehouse using SQL Server, where sales data from different systems is combined, cleaned, and prepared for business analysis and reporting.

🎯 Objectives
Build a centralized data warehouse to bring together data from multiple business sources.

Use SQL to perform data cleaning, transformation, and integration tasks.
Design a data model that supports efficient analytical queries and dashboards.
Generate insights into key business areas such as customer activity, product performance, and sales patterns.

🧱 Project Scope
Data Sources: Two separate CSV datasets (ERP and CRM systems).
Data Cleaning: Handle duplicates, missing values, and inconsistencies before loading.
Integration: Merge both datasets into a unified structure for analysis.
Focus: Work with the most recent dataset (no historical tracking).
Documentation: Clearly describe the data model and transformation steps for business and technical users.

📊 Tools & Technologies
SQL Server for database design and querying
ETL techniques for data transformation
Data Modeling for analytics
